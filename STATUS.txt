│                      🔧 CAMBIOS REALIZADOS                                │
└────────────────────────────────────────────────────────────────────────────┘

Problema 1: Login 404
  ❌ Origen: AdminApps backend en puerto 8000 interfería
  ✅ Solución: Matar AdminApps, IsoSmart en puerto 8001
  ✓ Verificado: Login retorna tokens válidos

Problema 2: Frontend IP Hardcoded
  ❌ Origen: .env apuntaba a 192.168.100.100 (IP antigua)
  ✅ Solución: Actualizar a localhost:8001/api
  ✓ Verificado: Frontend conecta correctamente

Problema 3: Endpoint URL Mismatches
  ❌ Origen: Frontend espera /api/stakeholders/ pero backend sirve /api/sie/stakeholders/
  ✅ Solución: Agregar URL aliases en Django urls.py
  ✓ Verificado: Todos los endpoints retornan 200

Problema 4: Acceso vía Dominio
  ❌ Origen: No configurado Nginx ni /etc/hosts
  ✅ Solución: Crear scripts de instalación automática
  ⏳ Próximo paso: Ejecutar setup_domain.sh

┌────────────────────────────────────────────────────────────────────────────┐
│                    🚀 INSTRUCCIONES RÁPIDAS                              │
└────────────────────────────────────────────────────────────────────────────┘

OPCIÓN 1: Desarrollo Local (SIN Nginx)
  $ cd frontend && npm run dev
  → Accede a http://localhost:3002

OPCIÓN 2: Con Dominio Local (RECOMENDADO)
  $ sudo bash setup_domain.sh
  → Accede a http://isosmart.local
  (requiere permisos de sudo)

OPCIÓN 3: Desde Otra PC en la Red
  1. Ejecutar setup_domain.sh en el servidor
  2. En tu PC, agregar a /etc/hosts:
     <IP_DEL_SERVIDOR>    isosmart.local
  3. Accede a http://isosmart.local
